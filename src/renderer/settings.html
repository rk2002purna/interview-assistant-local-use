🗣 Answer Style (how spoken answers sound)

Controls how voice-question answers are phrased. Conversational makes scenario & behavioral answers flow like a real person (STAR woven into sentences, no bullet dumps). This only changes the prompt wording, so it adds no response delay.

🎙 Speech-to-Text (Voice → Text)




Transcription tries the primary first; if it fails (rate limit, quota, outage), it automatically tries the fallback. You can set either provider as primary or fallback. English is pinned. Add the matching API key(s) below (Groq and/or Deepgram).
